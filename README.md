# 에코몬 성장 게임

환경 실천 행동을 선택하여 에코 점수를 얻고,
에코몬을 성장시키는 바이브 코딩 연습 게임입니다.

> 게임의 에코 점수는 실제 탄소 감축량이 아닌 수업용 게임 점수입니다.

---

## 오늘의 학습 목표

활동을 마치면 다음을 할 수 있습니다.

- GitHub Classroom 과제를 수락할 수 있다.
- GitHub Codespaces에서 웹 프로젝트를 실행할 수 있다.
- HTML과 CSS를 간단하게 수정할 수 있다.
- AI에게 기능을 작은 단위로 요청할 수 있다.
- AI가 작성한 코드를 실행하고 테스트할 수 있다.
- 오류의 현상과 재현 방법을 설명할 수 있다.
- 변경사항을 커밋하고 GitHub에 푸시할 수 있다.

---

## 게임 목표

환경 실천 행동을 선택해 에코 에너지를 모으세요.

| 점수 | 에코몬 단계 |
|---:|---|
| 0점 | 🥚 잠든 에코몬 알 |
| 20점 | 🌱 새싹 에코몬 |
| 40점 | 🌿 초록 에코몬 |
| 70점 | 🌳 나무 에코몬 |
| 100점 | 🌍 지구 수호 에코몬 |

---

## 1. 프로젝트 실행하기

Codespace가 열리면 상단 메뉴에서 다음을 선택합니다.

```text
Terminal → New Terminal
```

터미널에 다음 명령어를 입력합니다.

```bash
npm start
```

다음 메시지가 나타나면 정상입니다.

```text
에코몬 성장 게임 서버가 실행되었습니다.
주소: http://localhost:3000
```

Codespaces에 나타나는 `Open in Browser`를 선택합니다.

자동으로 열리지 않는다면 다음 순서로 확인합니다.

1. 편집기 아래쪽의 `PORTS` 탭을 엽니다.
2. 3000번 포트를 찾습니다.
3. 지구본 모양 아이콘을 선택합니다.

---

## 2. 파일의 역할

| 파일 | 역할 |
|---|---|
| `index.html` | 게임의 내용과 화면 구조 |
| `styles.css` | 색상, 크기, 배치와 애니메이션 |
| `app.js` | 점수, 진화, 버튼 등의 게임 기능 |
| `MISSION.md` | 단계별 실습 미션 |
| `AI_LOG.md` | AI 활용 및 검증 기록 |
| `TEST_CHECKLIST.md` | 기능 테스트 결과 |
| `server.js` | 웹 서버, 수정하지 않음 |
| `package.json` | 실행 명령 설정, 수정하지 않음 |

---

## 3. 현재 고장 난 기능

처음 실행하면 다음 기능은 작동합니다.

- 게임 화면 표시
- 무작위 추천 미션
- 게임 초기화

다음 기능은 아직 완성되지 않았습니다.

- 환경 행동을 눌렀을 때 점수 획득
- 실천 횟수 증가
- 실천 기록 추가
- 점수에 따른 에코몬 진화
- 에코몬 애니메이션

`app.js`의 `TODO` 부분을 AI와 함께 완성하세요.

---

## 4. 바이브 코딩 작업 순서

1. 만들 기능을 한 문장으로 정합니다.
2. 관련 파일과 코드 위치를 찾습니다.
3. AI에게 수정 계획부터 요청합니다.
4. 한 번에 기능 하나만 구현합니다.
5. AI가 바꾼 코드를 읽습니다.
6. 웹페이지에서 직접 테스트합니다.
7. 오류가 있으면 현상과 재현 방법을 기록합니다.
8. 기능이 완성되면 커밋합니다.

---

## 5. AI 요청 예시

```text
현재 프로젝트는 HTML, CSS, 순수 JavaScript로 만든
초보자용 에코몬 성장 게임이야.

app.js의 actionButtons 클릭 이벤트 TODO 부분만 완성하려고 해.

환경 행동 버튼을 누르면 다음과 같이 작동해야 해.

1. 누른 버튼의 data-action 값을 가져온다.
2. data-points 값을 숫자로 가져온다.
3. 행동 전 에코몬 단계 번호를 저장한다.
4. ecoScore에 점수를 더한다.
5. actionCount를 1 증가시킨다.
6. records 배열 맨 앞에 action과 points를 추가한다.
7. render()를 실행한다.
8. 단계가 바뀌었으면 진화 애니메이션을 실행한다.
9. 단계가 같으면 점프 애니메이션을 실행한다.

조건:
- HTML, CSS, 순수 JavaScript만 사용한다.
- 외부 라이브러리를 추가하지 않는다.
- server.js와 package.json은 수정하지 않는다.
- 전체 app.js를 다시 작성하지 않는다.
- 기존 기능을 삭제하지 않는다.

먼저 변경 계획을 설명하고,
그다음 TODO 부분에 필요한 코드만 제안해 줘.
마지막에 내가 직접 수행할 테스트도 알려 줘.
```

## 6. AI 코드 확인 질문

AI가 코드를 작성하면 다음을 확인합니다.

- 어떤 파일이 변경되었는가?
- 요청하지 않은 파일까지 변경하지 않았는가?
- `data-points`를 숫자로 변환했는가?
- 점수와 실천 횟수가 올바르게 증가하는가?
- 진화 기준 점수에서 단계가 바뀌는가?
- 100점을 넘겨도 진행률 막대가 화면을 벗어나지 않는가?
- 브라우저 콘솔에 빨간색 오류가 없는가?

## 7. 오류가 발생했을 때

다음 양식으로 AI 또는 선생님에게 질문합니다.

```text
하려던 일:
환경 행동 버튼을 누르면 점수가 증가하게 하려고 했다.

재현 순서:
1. 게임 페이지를 새로고침했다.
2. 텀블러 사용 버튼을 눌렀다.

실제 결과:
점수는 증가하지만 실천 기록이 표시되지 않는다.

기대 결과:
점수가 10 증가하고 기록 목록에
'텀블러 사용하기 +10점'이 나타나야 한다.

오류 메시지:
브라우저 콘솔의 오류 메시지를 붙인다.

관련 파일:
app.js

전체 파일을 다시 작성하지 말고,
가능한 원인과 확인 위치를 먼저 설명해 줘.
```

## 9. 커밋하고 GitHub에 저장하기

### VS Code 화면 이용

1. 왼쪽의 `Source Control` 아이콘을 선택합니다.
2. 변경된 파일을 확인합니다.
3. 커밋 메시지를 입력합니다.
4. `Commit`을 선택합니다.
5. `Sync Changes` 또는 `Push`를 선택합니다.

커밋 메시지 예시:

```text
에코몬 이름과 게임 디자인 변경
환경 행동 점수 기능 구현
에코몬 진화 기능 테스트 완료
```

### 터미널 이용

```bash
git status
git add .
git commit -m "환경 행동 및 에코몬 진화 기능 구현"
git push
```

- [ ] 색상 또는 에코몬 이름을 수정했다.

- [ ] 실천 횟수가 증가한다.

- [ ] 점수에 따라 에코몬이 진화한다.
- [ ] 진행률 막대가 올바르게 표시된다.
- [ ] 추천 미션 버튼이 작동한다.
- [ ] 초기화 기능이 작동한다.
- [ ] 브라우저 콘솔에 오류가 없다.
- [ ] `AI_LOG.md`를 작성했다.
- [ ] `TEST_CHECKLIST.md`를 작성했다.
- [ ] 최종 변경사항을 커밋하고 푸시했다.

## 안전 수칙

- 이름, 전화번호, 이메일 등의 개인정보를 입력하지 않습니다.
- 비밀번호, GitHub 토큰, API 키를 입력하지 않습니다.
- AI가 만든 코드를 검토하지 않고 바로 실행하지 않습니다.
- 다른 학생의 결과물을 그대로 복사하지 않습니다.
- 실제 환경 수치처럼 보이는 정보를 임의로 만들지 않습니다.
